PWA Icons for Resonance

This app requires the following icon files in /public:

  • icon-192.png — 192x192 pixels
  • icon-512.png — 512x512 pixels

Icons should be square PNG images with a transparent or solid background. The maskable purpose means icons should include padding (~10%) for safe zone masking on Android.
