The first 50 buyers are the founding members of Resonance. They pay the same full price as everyone after them and get three things in return:

v0.8.1 — Downloads that work

2026-08-17 · GitHub release

Every installer is now built and published automatically on release — including the Android APK, which no longer needs a manual upload.

New

  • Automated installers — Windows, macOS (Intel + Apple Silicon), Linux, and Android are all built in CI and attached to the release with checksums. The download page always points at the latest.
  • Android APK in the release — a real downloadable APK for arm64 and armv7 devices, no side-links required.

Fixed

  • Payment backend now talks to the correct Dodo Payments API endpoint (test mode), configured via the DODO_API_BASE environment variable.
  • Release pipeline no longer races: only the installer workflow publishes tags, so every release has a complete, verified asset set.

v0.8.0 — Resonance Intelligence

2026-08-16 · GitHub release

The release where Resonance starts understanding your library instead of just playing it.

New

  • Resonance Intelligence — a new Intelligence page (Pro): forgotten gems, rediscovery mixes for the last year, decade journeys through your albums, and sound-alikes matched on shared musical signals. All of it is computed on your server. Your library never leaves home.
  • Lifetime licenses — a $119 pay-once tier alongside annual Pro. Lifetime keys never expire; they unlock the same Pro features.
  • Real pricing — the upgrade page now has honest tiers (Free / Pro $29 a year / Lifetime / Enterprise) with direct checkout. No more placeholder copy.
  • The website — resonance.app: home, honest comparison table, download page with a Docker one-liner, and a pricing page.

Fixed

  • Database errors now log the actual error instead of a dead generic message.
  • Test seed data corrected for the intelligence queries (play counts and days-since-played were swapped in places).

Privacy

  • Nothing changed — and now it's documented. The privacy page lists every outbound connection the server can make, audited against the source.
