Docker — one command

The server component (backend + web app) in a single container:

docker run -d --name resonance \
  -p 127.0.0.1:8080:8080 \
  -v ~/Music:/music:ro \
  -v resonance-data:/data \
  ghcr.io/pandejesal/resonance:latest

Point the volume at your music directory. First run asks you to create an admin account, then scan your library from Settings. A full docker-compose.yml lives in the repo.

Prefer to build from source?

git clone https://github.com/pandejesal/resonance.git
cd resonance
npm --prefix frontend ci && npm --prefix frontend run build
cargo build --release --manifest-path backend/Cargo.toml
