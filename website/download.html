Android — APK

The native Android app (WebView client with the full backend embedded) ships as a versioned APK on every release. Grab the latest from the GitHub Releases page — look for resonance-<version>-android.apk. Sideloading: allow "Install unknown apps" for your browser or file manager, then open the downloaded file.

Download for Android

Android 10 or newer, arm64 and armv7. No Play Store listing yet — the APK is signed with the debug key, which is fine for sideloading; store-grade signing arrives at launch. On iPhone? Install the PWA instead (add to home screen).

Docker — one command

The server component (backend + web app) in a single container:

docker run -d --name resonance \
  -p 127.0.0.1:8080:8080 \
  -v ~/Music:/music:ro \
  -v resonance-data:/data \
  ghcr.io/pandejesal/resonance:latest

Point the volume at your music directory. First run asks you to create an admin account, then scan your library from Settings. A full docker-compose.yml lives in the repo.

Prefer to build from source?

git clone https://github.com/pandejesal/resonance.git
cd resonance
npm --prefix frontend ci && npm --prefix frontend run build
cargo build --release --manifest-path backend/Cargo.toml
